Soundabet Adventures PWA — upload the ZIP directly to a static HTTPS host. The index.html must be at the root of the published site. Open the resulting HTTPS address in Chrome on Android, use menu > Add to Home screen / Install app. This version contains NO verified phoneme recordings. Letter names use browser speech synthesis. In Settings an adult can record phonemes using the microphone, stored privately in browser IndexedDB. Recordings are not uploaded and can be lost if browser data is cleared. The PWA has not been device tested. You own the original app source; hosting has separate terms. Do not upload children’s private information.
